# Restaurant Order Management System 🍽️

An academic Java project that implements a **Restaurant Order Management System** using **Object-Oriented Programming (OOP)** concepts.

## 📌 Project Description

The system is designed to manage restaurant orders, meals, and drinks. It allows users to add different items to an order, enter item details, and calculate the total order price.

## ✨ Features

* Manage multiple customer orders.
* Add different types of items, including meals and drinks.
* Support different meal sizes: Small, Medium, and Large.
* Classify drinks as Hot or Cold.
* Add items to orders.
* Calculate the total order price.
* Display detailed order information.
* Calculate prices in Jordanian Dinars (JD).
* Interactive console-based input.

## 🧩 OOP Concepts Applied

* Classes & Objects
* Encapsulation
* Inheritance
* Polymorphism
* Method Overriding
* Constructors
* ArrayList Collections

## 🛠️ Technologies Used

* Java
* Java OOP
* Java Collections
* NetBeans
